GitHub Integration

Connect to your GitHub repository so the CMS can read and publish content directly. Requires a Personal Access Token with repo scope.
How to create a PAT: GitHub → Settings → Developer Settings → Personal Access Tokens → Tokens (classic) → Generate new token. Select the repo scope. Copy the token — it's only shown once.
Format: owner/repo-name
Stored locally in your browser only — never sent anywhere except GitHub's API.
